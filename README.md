# SGVue — downloads

SGVue is a read-only IFC model viewer for BIM coordination review. Models are parsed and viewed on your own computer and are never changed.

Download the latest version from **[Releases](https://github.com/sgvue/releases/releases)**.

## Install or update (Windows)

1. Download `SGVue-<version>-setup.exe` from the latest release.
2. Close SGVue if it is open.
3. Run the setup file. The app is not code-signed yet, so Windows may show "Windows protected your PC" — choose **More info → Run anyway**.
4. Installing over an existing copy updates it in place. Your settings, API key, recent files and saved views are kept.

Check which version you have under **Help › About**. **Help › Check for updates…** opens this page.
